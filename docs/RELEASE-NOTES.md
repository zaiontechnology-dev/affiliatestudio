# Zaion Affiliate Studio 1.0.0 — Notas da versão

Primeira versão da Desktop Edition. Consulte `CHANGELOG.md` para a lista completa.

## Destaques
- Zaion AutoPilot com fila persistente, anti-repetição e recuperação após reinício.
- Integração Shopee Affiliate Open API e Telegram Bot API (requerem suas credenciais).
- WhatsApp em modo assistido para grupos tradicionais.
- Zaion Offer Score, Price Radar, Smart Copy, Analytics, backups automáticos.

## Limitações conhecidas
- Integrações reais ainda não validadas com credenciais.
- Sem assinatura de código (alerta do SmartScreen).
- Mercado Livre, SHEIN, Amazon, AliExpress, Magalu e Temu: apenas CSV/cadastro manual.
- Automações não funcionam com o computador desligado, suspenso ou sem internet.
